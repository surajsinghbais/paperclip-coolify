# Deploy Paperclip on Coolify

Fully automated — deploys, onboards, and starts with zero SSH needed.

## Requirements

- Coolify v4 server
- **2+ GB RAM**, 2+ CPU cores, 10 GB disk
- At least one LLM API key (Anthropic, OpenAI, or Gemini)

## Deploy Steps

### 1. Push this repo to your GitHub/GitLab

```bash
git remote add mine https://github.com/YOUR_USERNAME/paperclip.git
git push mine master
```

### 2. In Coolify

1. **Projects → New Project** → name it → enter production environment
2. **"+ Add New Resource" → Docker Compose**
3. Connect your Git repo
4. Set **Docker Compose Location** to: `docker-compose.coolify.yml`
5. Set **Branch** to: `master`

### 3. Environment Variables

Add these in Coolify's **Environment Variables** tab:

| Variable | Required | Value |
|---|---|---|
| `ANTHROPIC_API_KEY` | ✅ (or another LLM key) | Your Anthropic API key |
| `OPENAI_API_KEY` | Optional | Your OpenAI API key |
| `GEMINI_API_KEY` | Optional | Your Gemini API key |
| `PAPERCLIP_ALLOWED_HOSTNAMES` | Optional | Your domain if using custom domain |

> **Note:** `BETTER_AUTH_SECRET` and `PAPERCLIP_PUBLIC_URL` are auto-generated by Coolify
> via `SERVICE_PASSWORD_*` and `SERVICE_FQDN_*` magic variables.

### 4. Deploy

Click **Deploy**. First build takes 5–10 minutes (builds Node.js monorepo + installs CLI tools).

### 5. Access

Once deployed, open your Coolify FQDN in a browser. The auto-onboard creates a
quickstart config on first boot — follow the signup flow to create your admin account.

## What's Included

| File | Purpose |
|---|---|
| `docker-compose.coolify.yml` | Coolify-optimized compose with auto-config |
| `Dockerfile.coolify` | Production image + auto-onboard entrypoint |
| `scripts/coolify-entrypoint.sh` | First-boot auto-onboard, then normal startup |

## Troubleshooting

| Problem | Fix |
|---|---|
| Build killed (exit 137) | Server needs more RAM. Add 4GB swap: `fallocate -l 4G /swapfile && chmod 600 /swapfile && mkswap /swapfile && swapon /swapfile` |
| Container restarts in loop | Check logs — likely missing `BETTER_AUTH_SECRET`. Coolify should auto-generate it via `SERVICE_PASSWORD_BETTER_AUTH_SECRET` |
| Can't access UI | Verify Coolify FQDN is set and proxy is routing to port 3100 |
| "Embedded Postgres" error | The Dockerfile.coolify includes embedded-postgres. If on ARM, set `DATABASE_URL` to an external Postgres instead |

## Architecture

```
Coolify Proxy (Traefik/Caddy)
  └─ paperclip container (port 3100)
       ├─ Node.js server + embedded PostgreSQL
       ├─ React UI (served by Node)
       ├─ Agent runtimes (Claude, Codex, Gemini, etc.)
       └─ /paperclip volume (DB data, workspaces, uploads)
```
